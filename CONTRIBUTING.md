# Contributing to Setup-Android-build-environment

First off, thanks for taking the time to contribute! 🎉

## How Can I Contribute?

### Reporting Bugs
If you encounter a build failure, AAPT2 error, or an issue with a specific Linux distribution/Termux, please open an issue and provide:
- Your system architecture (`uname -m`)
- The OS name and version (e.g., Ubuntu 24.04, Termux, Debian 12)
- The exact error logs.

### Suggesting Enhancements
Feel free to open an issue or pull request if you want to add support for a new package manager or improve the script's efficiency.

### Pull Requests
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/AmazingFeature`).
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`).
4. Push to the branch (`git push origin feature/AmazingFeature`).
